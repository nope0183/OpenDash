OpenDash v2.1.2

Прошивка ESP32 CYD для телеметрии Ninebot G30 / ES4. Установщик работает в браузере через Web Serial и не требует PlatformIO.

Перед установкой: выберите правильную ревизию дисплея. Если сомневаетесь, посмотрите маркировку контроллера на плате или проверьте, какая прошивка уже стоит. Установка стирает flash и настройки.

ST7789

обычно ревизия CYD 2 USB

Сборка cyd_2usb. Ставит загрузчик, таблицу разделов с двумя OTA-слотами и приложение OpenDash.

Нужен Chrome или Edge на компьютере. Откройте страницу по HTTPS.

ILI9341

ревизия CYD с ILI9341

Сборка cyd_ili9341. Те же разделы и OTA, отличается только драйвер дисплея.

Нужен Chrome или Edge на компьютере. Откройте страницу по HTTPS.

Как прошить

  1. Подключите CYD к компьютеру USB-кабелем с передачей данных.
  2. Нажмите кнопку установки и выберите последовательный порт платы.
  3. Подтвердите стирание flash. Если плата не входит в режим загрузки, зажмите BOOT (GPIO 0), нажмите RESET, отпустите BOOT и повторите установку.
  4. После завершения плата перезагрузится. Настройки сохраняются в энергонезависимой памяти (NVS); при первой установке они сбрасываются.

После установки

Обновления можно ставить по воздуху: Настройки → Обновление OTA включает Wi-Fi точку доступа. Пароль и адрес показываются на экране. Для OTA используйте файл .bin из Releases.

Первая установка этой версии важна: в ней появилась таблица разделов с OTA-слотами, поэтому одной записи приложения недостаточно. Веб-установщик записывает полный набор разделов.

Совместимость

  • ESP32-2432S028 «CYD», 4 MB flash, без PSRAM.
  • ST7789 или ILI9341; тач XPT2046.
  • Ninebot G30 / ES4; для расширенных функций — SHFW.
  • Chrome / Edge с Web Serial; Firefox и Safari не поддерживаются.

Исходники: github.com/nope0183/OpenDash. Прошивка предоставляется «как есть»; не используйте её во время движения без проверки на безопасном стенде.
